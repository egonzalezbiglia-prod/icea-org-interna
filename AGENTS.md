# Especificaciones del Sistema y Reglas del Proyecto

## 🏗️ Arquitectura y Stack
- Lenguaje: TypeScript (Tipado estricto)
- Framework: Next.js + React (sobre Node.js)
- Base de datos: Firebase Firestore (usando firebase-admin)
- Idioma: Todo el código y los comentarios deben escribirse estrictamente en Español.

## ⚙️ Comandos del Proyecto (Usar pnpm)
- Instalación: `pnpm install`
- Desarrollo local: `pnpm dev`
- Producción/Build: `pnpm build` y `pnpm start`
- Formateo/Lint: `pnpm lint`
- Nota: No hay comandos de test configurados actualmente.
