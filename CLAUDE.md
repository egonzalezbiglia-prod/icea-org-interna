# Instrucciones para Claude Code

## 📌 Configuración Compartida
- Revisa SIEMPRE el archivo @AGENTS.md antes de escribir código para respetar el stack de TypeScript, Next.js y Firebase, así como el uso de pnpm.

## 🤖 Directrices de Trabajo y Relevo
- No dupliques funciones. Revisa los componentes existentes en el proyecto.
- Cada vez que termines una tarea, escribe OBLIGATORIAMENTE un resumen de lo que hiciste en la última línea del archivo 'CHANGES.log' usando el formato: "- [CLAUDE] Breve descripción de la tarea realizada".
- Al terminar, detén tu ejecución para cederle el turno a Codex.
